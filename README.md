# Proyecto Final OpenGL

Este repositorio contiene únicamente el código fuente del proyecto y la carpeta de shaders para trabajo colaborativo.

## Contenido
- Carpeta `codigo/` con archivos `.cpp` y `.h`
- Carpeta `shaders/`

## No incluido en este repositorio
- Modelos 3D
- Texturas
- Archivos compilados
- Configuración local del entorno

## Assets del proyecto
Los modelos y las texturas se descargan desde este enlace:

[Descargar modelos y texturas](https://drive.google.com/drive/u/2/folders/1NMsd_3235AgwIkVdMTps7zDhCENXGGNe)

## Instrucciones
1. Clonar este repositorio.
2. Descargar los assets desde el enlace de Drive.
3. Colocar las carpetas pesadas en la ruta correspondiente de su proyecto local.
4. Trabajar únicamente sobre los archivos dentro de `codigo/` y `shaders/`.

## Flujo recomendado
- `main`: versión estable
- `develop`: integración de cambios
- `feature/nombre-cambio`: cambios específicos
- `fix/nombre-error`: correcciones puntuales
